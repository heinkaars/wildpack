Onboarding flow (only first-time)

- Welcome message   
- “Choose your look”  
- “Choose your name”   
- Guided first capture \[redirect to Capture flow\]

Lifelist flow (home / return-visit landing)

- System reveals User (look \+ name)   
- System reveals lifelist overview with captured wildlife  
- User can view species card of captured wildlife  
  - Photo, name, description, date, location etc  
  - AMA  
- System shows Streak counter   
- System shows milestone badges  
- \[Capture button → launches Capture flow\]

Capture flow

- User open native device camera within app  
  - User shoots photo  
  - Or User uploads photo  
- System identifies photo  
- System celebrates (threshold check)  
  - one combined/stacked celebration modal — new species \+ milestone \+ streak   
- System auto adds wildlife to lifelist  
- User views species card  
  - Photo, name, description, date, location etc  
  - AMA  
- \[Returns to Lifelist\]

Storefront flow

- Promote shop in AMA  
- Deep link to external shopify storefront
